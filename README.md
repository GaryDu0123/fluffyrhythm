# Fluffy Rhythm — Local Backup

English | [简体中文](README.zh-CN.md)

This project is a backup of ubique's mini-game [Fluffy Rhythm](https://ubique.city/fluffyrhythm/).

## Requirements

Node.js 18 or later. No additional dependencies.

## Start

```sh
npm start
```

Open [http://127.0.0.1:4173/fluffyrhythm/](http://127.0.0.1:4173/fluffyrhythm/).

On Windows, you can also double-click [`start.cmd`](start.cmd).

## GitHub Pages

In the repository's **Settings → Pages → Build and deployment**, set **Source** to **GitHub Actions**. Push to the default branch to deploy `public/` automatically, or run **Deploy to GitHub Pages** manually from the **Actions** tab on that branch.

## Notes

Play with **A / S / D / F** or tap the four lanes. External links require internet access.
