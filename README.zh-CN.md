# Fluffy Rhythm — 本地备份

[English](README.md) | 简体中文

本项目是 ubique 的小游戏 [Fluffy Rhythm](https://ubique.city/fluffyrhythm/) 的备份。

## 依赖

Node.js 18 或更新版本，无需安装其他依赖。

## 启动

```sh
npm start
```

访问 [http://127.0.0.1:4173/fluffyrhythm/](http://127.0.0.1:4173/fluffyrhythm/)。

Windows 也可双击 [`start.cmd`](start.cmd) 启动。

## GitHub Pages

在仓库的 **Settings → Pages → Build and deployment** 中，将 **Source** 设置为 **GitHub Actions**。推送到默认分支后会自动部署 `public/`，也可在 **Actions** 页面选择该分支，手动运行 **Deploy to GitHub Pages**。
